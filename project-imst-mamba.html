IMST-
MAMBA

ICU 결측치를 단순 보정 대상이 아니라 never·recent·stale 상태를 가진 정보로 해석해 조기 패혈증 예측에 활용했습니다.

TYPEPersonal Research Project
ROLEModeling · Experiment · Evaluation
DATAPhysioNet Sepsis Challenge 2019
STACKPyTorch · Mamba · Bootstrap CI
Core question
측정되지 않은 시간 자체를 환자 상태에 대한 정보로 사용할 수 있는가?
Problem

ICU의 결측은 완전히 무작위가 아닙니다.

어떤 활력징후는 환자 상태나 의료진 판단에 따라 더 자주 측정됩니다. 따라서 값만 대치하고 결측 패턴을 제거하면, “왜 지금 측정되었는가”와 “얼마나 오래 관측되지 않았는가”라는 신호를 잃을 수 있습니다.

Approach

결측을 세 가지 상태로 나누었습니다.

  • Never — 한 번도 관측되지 않은 변수
  • Recent — 최근에 관측되어 비교적 신선한 변수
  • Stale — 마지막 관측 이후 시간이 오래 지난 변수

값, 관측 마스크, staleness, inter-event time을 함께 입력하고, temporal decay와 selective state-space block을 결합했습니다.

Architecture

측정값과 관측 상태를 같은 시간축에서 처리했습니다.

NEVERnot observed
RECENTfresh signal
STALEelapsed signal
IMST-MAMBA
missingness-aware selective state space model

패혈증 예측을 주 과제로 두고 Mortality와 SOFA 보조 헤드를 추가해 멀티태스크 정규화를 적용했습니다.

System connection

모델 연구와 시스템 통합을 서로 다른 관점으로 설명합니다.

이 페이지는 결측 상태 정의, 모델 구조, Baseline 비교와 Ablation처럼 모델 자체의 연구 질문을 다룹니다. Medi-Matrix는 같은 시계열 아이디어를 3D 영상·인증·스토리지·WebSocket과 연결하며 시스템 통합 질문을 다룹니다.

중복이 아닌 역할 분리. IMST-Mamba는 독립 연구 결과이고 Medi-Matrix는 이를 활용하는 멀티모달 시스템 프로토타입입니다. 단, 현재 공개 Medi-Matrix의 시계열 결과는 실제 학습 모델 추론이 아니라 Demo/실험적 모듈입니다.

Evaluation

전체 평균과 하위집단 성능을 구분했습니다.

0.7791IMST-Mamba overall AUROC
0.8514Long-stay subgroup AUROC
−0.121Staleness 제거 시 AUROC 변화
44.7hMean Early Warning Time

전체 집단에서는 Transformer가 더 높은 AUROC를 기록했지만, 장기 입원 환자 하위집단에서는 IMST-Mamba가 더 높은 결과를 보였습니다. 이를 전체 모델 우위로 과장하지 않고, 복잡한 결측 패턴이 있는 집단에서의 가능성으로 제한했습니다.

Ablation

어떤 입력이 실제로 기여했는지 확인했습니다.

Staleness 신호를 제거했을 때 AUROC가 0.121 감소해, 단순 binary mask보다 마지막 관측 이후 경과 시간이 더 중요한 정보일 가능성을 확인했습니다.

Limits

외부 검증 없이 임상적 우위를 주장하지 않았습니다.

단일 공개 데이터셋 기반 결과이며, 외부 병원 데이터 검증, calibration, prospective workflow 평가가 필요합니다. 모델 성능 수치만으로 임상적 유용성을 주장할 수 없음을 명시했습니다.

저장소의 연구·제출 상태 표기는 실제 진행 상황과 일치하도록 최종 제출 전 다시 확인해야 합니다.
Learning

평균 점수보다 어떤 환자에게 도움이 되는지가 중요했습니다.

의료 AI에서는 전체 AUROC 하나보다 하위집단, 조기경보 시간, calibration과 ablation을 함께 봐야 모델이 실제로 어떤 조건에서 가치를 만드는지 설명할 수 있다는 점을 배웠습니다.
