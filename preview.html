02 — DEMO / SYNTHETIC DATA

MEDI-
MATRIX

3D 의료영상과 ICU 생체신호를 결합하면서, 파일 입력 검증·인증·사용자 데이터 격리까지 함께 설계한 의료 AI 프로토타입입니다.

TYPEPersonal Prototype
ROLEArchitecture · Backend · Security
STATUSDemo inference / Synthetic data
STACKFastAPI · React · Three.js · Supabase
Core question
의료 AI 데모를 만들 때, 모델보다 먼저 지켜야 할 데이터 경계는 무엇인가?
Problem

의료 파일은 일반 이미지처럼 다룰 수 없습니다.

NIfTI와 NumPy 의료영상은 다차원 배열이므로 파일 형식, 차원, 값 범위와 크기를 잘못 처리하면 서버 자원과 보안에 영향을 줄 수 있습니다. 기존 코드에는 추적된 환경 변수 파일, 위험한 pickle 로딩, 입력값 검증 부족과 문서·구현 불일치가 있었습니다.

My role

모델 데모와 운영 경계를 분리했습니다.

  • NIfTI·NumPy 파싱과 GLB Mesh 변환 흐름 정리
  • 파일 크기·dtype·차원·NaN/Inf 검증과 임시파일 정리
  • JWT 인증, Private Storage와 사용자별 경로 격리 설계
  • Vitals WebSocket replay와 Demo/Model inference mode 분리
Decision

업로드 파일과 공개 URL을 신뢰하지 않았습니다.

Safe parsing

`allow_pickle=False`를 적용하고 object dtype, 비정상 차원, NaN·Inf 및 과도한 파일 크기를 차단했습니다.

Private storage

생성된 Mesh와 Vitals 파일을 사용자 경로로 격리하고, 인증된 사용자에게만 만료형 Signed URL을 발급하도록 설계했습니다.

Explicit inference boundary

공개 배포는 합성 데이터 기반 Demo Inference로 두고, 실제 모델 추론은 별도 의존성과 자원 조건을 요구하도록 분리했습니다.

System

3D 영상과 시계열 데이터를 안전한 처리 흐름으로 연결했습니다.

세 결과물은 같은 문제의 연속선에 있지만, 현재 구현 수준은 서로 다릅니다. 그래서 프로젝트를 합쳐 보이게 만들기보다 관계와 경계를 함께 표시했습니다.

03 — HYPOTHESIS TO EVIDENCE

MEDICAL
INSIGHT

“공포 제목이 조회수를 높인다”는 직관을 단순 비교에서 끝내지 않고, 교란변수와 하위집단을 통제해 결론을 다시 검증했습니다.

TYPEPersonal Data Project
ROLECollection · Analysis · Dashboard
METHODPSM · Fixed Effects · DiD
STACKPython · pandas · statsmodels · Streamlit
Core question
공포 키워드가 조회수를 올린 것인가, 채널 규모와 영상 나이의 착시인가?
Problem

첫 번째 결과는 그럴듯했지만 충분하지 않았습니다.

단순 비교에서는 공포 키워드를 사용한 의료 영상의 조회수가 약 2.1배 높게 나타났습니다. 그러나 오래된 영상과 대형 채널이 공포 표현을 더 많이 사용했다면, 이 차이를 제목 효과라고 결론내릴 수 없었습니다.

Data

분석 단위를 확장하고 교란요인을 수집했습니다.

3,713분석 영상
921채널
19,232수집 댓글
37질환 카테고리

영상 나이, 채널 구독자 규모, Shorts 여부, 채널 유형을 추가해 공포 키워드와 조회수 사이의 관계를 단계적으로 다시 확인했습니다.

Decision

분석 방법마다 다른 질문을 맡겼습니다.

Age adjustment

오래 업로드된 영상이 조회수를 더 많이 누적한 효과를 분리하기 위해 영상 나이를 보정했습니다.

Propensity Score Matching

공포 표현 사용 집단과 미사용 집단의 채널 규모와 영상 특성 차이를 줄였습니다.

Channel fixed effects

채널 고유의 브랜드 영향력을 통제하고 같은 채널 내부에서 제목 표현의 차이를 확인했습니다.

Difference-in-Differences

COVID-19라는 외생적 사건 전후에 공포 표현 효과가 달라졌는지 검토했습니다.

Result

방법을 바꾸자 결론의 방향도 바뀌었습니다.

NAIVE2.1×

AGE ADJ.1.0×

PSM0.63×

가설을 증명하는 것보다 틀릴 가능성을 줄였습니다.
  • 영상 나이 보정 후 단순 효과가 소멸
  • PSM에서는 채널 규모 통제 후 0.63배의 역효과
  • 채널 고정효과에서는 같은 채널 내부 효과가 유의하지 않음
  • Medical Pro 채널 하위집단에서는 0.83배의 감소 방향
Limits

인과추론도 관찰 데이터의 한계를 넘지는 못합니다.

댓글 수집 범위, 측정되지 않은 교란변수, Shorts 추천 알고리즘, PSM 매칭 후 외적 타당성의 제한을 함께 기록했습니다. 결과는 “모든 의료 채널에서 공포 표현이 항상 역효과”라는 주장이 아니라, 단순 상관관계의 해석이 위험하다는 근거로 제한했습니다.

Learning

분석의 목적은 처음 세운 가설을 지키는 것이 아니었습니다.

설득력 있는 수치보다 올바른 비교 대상을 만드는 과정이 중요하다는 점, 그리고 결론이 바뀌는 것이 분석 실패가 아니라 검증의 성과일 수 있다는 점을 배웠습니다.

RESEARCH NOTE / R1TIME-SERIES ML · RELATED RESEARCH
R1 — RELATED RESEARCH

IMST-
MAMBA

ICU 결측치를 단순 보정 대상이 아니라 never·recent·stale 상태를 가진 정보로 해석해 조기 패혈증 예측에 활용했습니다.

TYPEPersonal Research Project
ROLEModeling · Experiment · Evaluation
DATAPhysioNet Sepsis Challenge 2019
STACKPyTorch · Mamba · Bootstrap CI
Core question
측정되지 않은 시간 자체를 환자 상태에 대한 정보로 사용할 수 있는가?
Problem

ICU의 결측은 완전히 무작위가 아닙니다.

어떤 활력징후는 환자 상태나 의료진 판단에 따라 더 자주 측정됩니다. 따라서 값만 대치하고 결측 패턴을 제거하면, “왜 지금 측정되었는가”와 “얼마나 오래 관측되지 않았는가”라는 신호를 잃을 수 있습니다.

Approach

결측을 세 가지 상태로 나누었습니다.

  • Never — 한 번도 관측되지 않은 변수
  • Recent — 최근에 관측되어 비교적 신선한 변수
  • Stale — 마지막 관측 이후 시간이 오래 지난 변수

값, 관측 마스크, staleness, inter-event time을 함께 입력하고, temporal decay와 selective state-space block을 결합했습니다.

System connection

모델 연구와 시스템 통합을 서로 다른 관점으로 설명합니다.

이 페이지는 결측 상태 정의, 모델 구조, Baseline 비교와 Ablation처럼 모델 자체의 연구 질문을 다룹니다. Medi-Matrix는 같은 시계열 아이디어를 3D 영상·인증·스토리지·WebSocket과 연결하며 시스템 통합 질문을 다룹니다.

중복이 아닌 역할 분리. IMST-Mamba는 독립 연구 결과이고 Medi-Matrix는 이를 활용하는 멀티모달 시스템 프로토타입입니다. 단, 현재 공개 Medi-Matrix의 시계열 결과는 실제 학습 모델 추론이 아니라 Demo/실험적 모듈입니다.

Evaluation

전체 평균과 하위집단 성능을 구분했습니다.

0.7791IMST-Mamba overall AUROC
0.8514Long-stay subgroup AUROC
−0.121Staleness 제거 시 AUROC 변화
44.7hMean Early Warning Time

전체 집단에서는 Transformer가 더 높은 AUROC를 기록했지만, 장기 입원 환자 하위집단에서는 IMST-Mamba가 더 높은 결과를 보였습니다. 이를 전체 모델 우위로 과장하지 않고, 복잡한 결측 패턴이 있는 집단에서의 가능성으로 제한했습니다.

Ablation

어떤 입력이 실제로 기여했는지 확인했습니다.

Staleness 신호를 제거했을 때 AUROC가 0.121 감소해, 단순 binary mask보다 마지막 관측 이후 경과 시간이 더 중요한 정보일 가능성을 확인했습니다.

Limits

외부 검증 없이 임상적 우위를 주장하지 않았습니다.

단일 공개 데이터셋 기반 결과이며, 외부 병원 데이터 검증, calibration, prospective workflow 평가가 필요합니다. 모델 성능 수치만으로 임상적 유용성을 주장할 수 없음을 명시했습니다.

저장소의 연구·제출 상태 표기는 실제 진행 상황과 일치하도록 최종 제출 전 다시 확인해야 합니다.
Learning

평균 점수보다 어떤 환자에게 도움이 되는지가 중요했습니다.

의료 AI에서는 전체 AUROC 하나보다 하위집단, 조기경보 시간, calibration과 ablation을 함께 봐야 모델이 실제로 어떤 조건에서 가치를 만드는지 설명할 수 있다는 점을 배웠습니다.
